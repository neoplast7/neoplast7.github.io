# NEO PLAST Website

سایت استاتیک فارسی و RTL برای نئو پلاست، آماده انتشار روی GitHub Pages.

## انتشار روی GitHub Pages
1. این پوشه را داخل یک Repository در GitHub آپلود کنید.
2. از Settings → Pages، بخش Source را روی `Deploy from a branch` بگذارید.
3. Branch را روی `main` و Folder را روی `/ (root)` قرار دهید.
4. Save را بزنید. بعد از چند دقیقه سایت با آدرس GitHub Pages شما در دسترس خواهد بود.

## نکته درباره پرداخت
در این نسخه «کارت به کارت» فعال است و «پرداخت آنلاین» به‌صورت غیرفعال/به‌زودی نمایش داده می‌شود.
سایت استاتیک GitHub Pages نمی‌تواند پرداخت را به‌صورت امن تأیید کند؛ بنابراین بعد از انتقال وجه، مشتری شماره پیگیری را وارد می‌کند و جزئیات سفارش با یک کلیک در واتساپ برای شماره نئو پلاست آماده می‌شود.
