# Neo PLAST ready website
این نسخه تک‌فایلی است: فقط `index.html` را در ریشه repository آپلود/جایگزین کنید.
- فارسی، عربی (عراقی) و انگلیسی
- انتخاب ۵ سایز: 25×35، 30×40، 37×47، 45×55، 65×55
- انتخاب تعداد
- سبد خرید با localStorage
- صفحه سفارش
- طراحی واکنش‌گرا برای موبایل
- لوگوی Neo PLAST و تصاویر به‌صورت داخلی در فایل؛ فایل عکس جداگانه لازم نیست.
- قیمت‌ها فعلاً «قیمت توافقی» هستند؛ برای قیمت‌گذاری، آرایه `prices` داخل فایل را تغییر دهید.
- پرداخت آنلاین واقعی نیاز به اتصال درگاه و اطلاعات پذیرنده دارد و در این نسخه فقط گزینه پرداخت نمایش داده می‌شود.
